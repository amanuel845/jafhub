Endpoints

  • /api/github/<path> — REST proxy to https://api.github.com
  • /api/graphql — GraphQL proxy
  • /api/meta — server info & auth mode

Security notes

  • The proxy never forwards to an arbitrary upstream.
  • Request headers are allowlisted; response headers are allowlisted.
  • CORS is off unless ALLOWED_ORIGINS is set.
  • Bodies are capped (1 MB REST, 256 KB GraphQL).
  • Browser tokens live in localStorage; use a fine-grained PAT with minimal scope.
